# Third-party components

Blux adapts selected Svelte components from [Open WebUI](https://github.com/open-webui/open-webui), without its Python backend or account system.

- Version: `v0.12.5`
- Commit: [`f7ac7ee10962ddec0017f5c29b6740d9b9c5faca`](https://github.com/open-webui/open-webui/commit/f7ac7ee10962ddec0017f5c29b6740d9b9c5faca)
- Original component files and checksums: [manifest.json](src/lib/upstream/open-webui/manifest.json)
- Blux adaptations: `src/lib/components/blux/`
